# Clear Dialogue

A plugin built with the assistance of AI in order to help customize the dialogue boxes, 
includes redraw support for OpenDyslexic and other fonts already included in the game.

## Features

- **OpenDyslexic Support**
- **Existing in-game fonts**
- **Color customization**
- **Text shadow**
- **Covers all common dialogue options**

## Development

Run a development client with the plugin loaded:

```bash
./gradlew run
```
